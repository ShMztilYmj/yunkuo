# 截图

目前仓库还没有随附截图。`.preview/` 下的调试截图**不要直接提交**：里面包含当时使用的订阅节点名称、
机场流量信息与出口 IP，属于真实数据。

## 自己截一套的步骤

```powershell
pnpm tauri dev
```

启动后按下面的清单各截一张（建议 1418 × 700，浅色主题 + 深色主题各一版）：

| 文件名 | 页面 | 注意 |
| --- | --- | --- |
| `overview.png` | 代理 → 概览 | 用测试订阅或把节点名改成 `节点 A/节点 B` |
| `proxies.png` | 代理 → 节点 | 同上，隐藏真实机场名与剩余流量 |
| `fingerprint.png` | 指纹浏览器 | 出口 IP 换成文档网段（如 `203.0.113.7`）或打码 |
| `ai-tools.png` | AI → 工具 | 不要露出真实账号邮箱与 token |

截图前先确认：

- 没有真实订阅链接、机场名称、流量余量；
- 没有真实出口 IP、本机用户名、磁盘路径；
- 没有账号邮箱、OAuth 头像、API Key。

## 放进 README

把图片放到 `docs/screenshots/`，然后在 README 的「快速开始」之后加：

```markdown
![概览](docs/screenshots/overview.png)
```

单张控制在 300 KB 以内，宽度 1400 px 左右即可。
